# 使用指南

> 从零把 知迹 跑起来，十分钟走完"算题 → 沉淀笔记 → 检索资料"的闭环。
> 想理解内部原理，读 [架构设计](架构设计.md)。

## 一、前置条件

- **Python 3.12+**
- **[uv](https://docs.astral.sh/uv/)**（依赖与虚拟环境管理）
- 可选：一个 OpenAI 兼容平台的 API Key（用真实模型时才需要；默认 Mock 不需要）

## 二、安装

```bash
uv sync
```

这一步会创建 `.venv` 并安装 LangGraph 等依赖。默认**不装** `langchain-openai`——
只有接真实模型时才需要它。

## 三、第一次运行（Mock，零成本）

```bash
uv run zhiji "帮我算一下 7 * 9"
```

预期输出：

```text
（模拟模型）根据工具返回的结果：63
```

这句话背后发生的事：意图被识别为"计算" → 路由到计算子智能体 → 模型请求调用
计算器工具（参数 `7 * 9`）→ 工具返回 `63` → 模型据此给出回答。**全程不联网、
不花额度。**

## 四、走一遍学习闭环

```bash
# 1. 沉淀一条笔记（写操作会先请求确认）
uv run zhiji "记住：我在准备月底的微积分测验"

#    如果不想交互确认，用 --yes 自动同意
uv run zhiji "记住：我在准备月底的微积分测验" --yes

# 2. 检索刚沉淀的内容
uv run zhiji "我的笔记里怎么讲微积分测验的？"
```

第 1 条命令会先打印：

```text
[需要确认] 保存到「日常沉淀」：《记住：我在准备月底的微积分测验》
  预览：记住：我在准备月底的微积分测验
  确认保存？(y/N)
```

输入 `y` 才落库——这就是 Human-in-the-Loop。

### AI 私教怎么聊（教学人格）

知迹 的回答遵循「私教」总纲（三条红线）：**个人数据优先**（你的笔记 /
错题本里有的先检索再答，并标注出处）、**引导优先于告知**（先给思路提示和分步
小问题，不直接甩答案）、**贴合掌握水平**（按你各学科的掌握度调整讲解深度）。

在此之上还有一套**输出规格**：核心结论先给并加粗、分层列点/表格、单段不超过 3 行、
结尾一定落到下一步（抛一个引导小问题，或确认下一个动作）——不会给你一坨没有结构
的长文，也不会用「还有什么可以帮你」这种开放式结尾收场。

以及一条**技术过程内隐**：回复的**正文**只讲教学，不讲执行——不出现工具名、接口名、
执行步骤或报错。查到资料会说「你的笔记里写过……（出处：某库）」，没查到就说
「这部分你还没有沉淀过」；就算写入失败也只会说「我先帮你留存，稍后同步到你的知识库中」。
执行细节（工具调用链、检索过程）保留在聊天面板的**过程流**里，供你想看时展开——
两者不冲突：面板给你透明度，正文给你干净的教学。

值得在聊天里试的话：

```bash
# 苏格拉底式讲解：不给完整答案，一步步引导你推导
uv run zhiji "讲一下定积分和不定积分的区别"

# 错题归因：检索你的误区记录，统计同类错误频次（需要先记过错题）
uv run zhiji "帮我分析一下我的错题，我哪里错了"

# 贴合掌握水平：薄弱学科多用类比讲基础，强势学科讲本质讲拓展
uv run zhiji "我的线性代数学得怎么样？接下来怎么复习？"
```

### 聊天里可以做的三件"非打字"的事

1. **传附件**：点 ＋ → 上传文件，或直接把 PDF/图片**拖进**输入框，也可以 **Cmd+V 粘贴截图**。
   附件会随下一条消息发给模型；图片上传后可以点缩略图全屏预览。
   （图片识别需要真实模型；Mock 模式下上传图片会提示配置真实模型。）
2. **开关权限**：＋菜单里的「允许完全访问」——打开后，保存笔记这类敏感操作不再逐次弹确认框；
   开启时 ＋ 按钮右上角有个小红点提示。
3. **换空间**：输入栏下方一行可切换本次对话归属的项目空间（记忆也按空间隔离）。

### 日程怎么用（收件箱 → 时间轴）

想用日程时的一个典型流程：

```text
1. 想起来一件事 → 点「＋ 新收件箱任务」或右下角 FAB，只写标题（不选时间）→ 先放收件箱
2. 有空了 → 收件箱里点「安排到今天 ›」→ 自动落进当天最早的空档
3. 想指定时间 → 点收件箱卡片打开编辑，用自绘的时间选择器（时/分双列，5 分钟一档，
   也有「现在」「上午 09:00 / 晚上 19:00 / 睡前 22:00」快捷键）与日期选择器（迷你日历）
4. 时间轴上 → 点右侧圆圈打勾表示完成（卡片划掉、变浅）；点卡片任意位置即可编辑
5. 空档处 → 鼠标悬在空白时段会出现「＋ 在这里加一件事」，点一下即以该时刻新建
```

排期规则（确定性，不调用模型）：时间轴固定 06:00–24:00；「安排到某天」取当天
**最早放得下的空档**，今天则从当前时刻之后开始找。

> 联网说明：搜索是多路召回——一次给 2-4 个不同角度的查询词，结果自动去重、
> 按权威度排序；默认后端为必应中国（零配置），也可在 `.env` 里配
> `ZHIJI_TAVILY_API_KEY`（tavily.com 免费注册）走 Tavily，稳定得多。搜索失败时
> 助手会如实说明"未能联网核实"，不会编造来源。文件都存在 `data/workspace/<用户>/`
> 里，路径穿越与系统其他位置一律拒绝。

## 六、命令行参数

| 参数 | 作用 |
| --- | --- |
| `message`（位置参数） | 本轮要说的话 |
| `--thread <id>` | 会话 id。相同 id 会**接着上一次**继续（断点持久化），默认 `local` |


## 七、接入真实模型

任何 OpenAI 兼容平台都可以。推荐把配置写进项目根目录的 `.env`（Git 忽略，
程序启动时**自动加载**，无需手动 source）：

```bash
uv sync --extra openai

# .env 内容（DeepSeek-V4.1-Flash 示例，API 模型名 deepseek-flash）：
# ZHIJI_LLM_PROVIDER=openai
# ZHIJI_MODEL=deepseek-flash
# ZHIJI_OPENAI_BASE_URL=https://api.deepseek.com/v1
# ZHIJI_OPENAI_API_KEY=你的密钥
# ZHIJI_MAX_OUTPUT_TOKENS=4096

uv run zhiji "讲解一下导数的几何意义"
```

也可以用环境变量临时覆盖（优先级高于 `.env`）。完整变量清单见
[`.env.example`](../.env.example)。注意：推理型模型务必设
`ZHIJI_MAX_OUTPUT_TOKENS=4096`，避免输出被"思考"吃光导致空回答。

> 2026-07 起 DeepSeek 的 `deepseek-chat` / `deepseek-reasoner` 型号已退役，
> 统一使用 `deepseek-flash`（V4.1-Flash）或 `deepseek-v4-pro`。

### 7.1 向量检索（Embedding）——强烈建议配置

主模型是 DeepSeek 时它**没有 /embeddings 接口**，向量服务要单独配（推荐智谱
`embedding-3`，或硅基流动免费的 `bge-m3`）。配好后知识库检索的语义路生效：
同义换词（资料写"导数"，问"变化率"）也能召回；不配则回落 mock（仅共享子串
相似）+ 纯关键词检索。

```bash
# .env 追加（智谱示例）：
# ZHIJI_EMBEDDING_PROVIDER=openai
# ZHIJI_EMBEDDING_BASE_URL=https://open.bigmodel.cn/api/paas/v4
# ZHIJI_EMBEDDING_API_KEY=你的智谱密钥
# ZHIJI_EMBEDDING_MODEL=embedding-3
# ZHIJI_EMBEDDING_DIM=2048
```

配好后重启后端；之前入库的资料要在阅读器里重新「编辑保存」一次才会按新
模型重建向量。

### 7.2 联网搜索——自动选择，无需配置

用 DeepSeek 做主模型时 `web_search` **自动走 DeepSeek 原生联网搜索**（服务端
搜索+抓网页全文+基于全文整理答案，质量最好的中文路径），无需任何额外配置。
想换/想加：配 `ZHIJI_BOCHA_API_KEY`（博查，中文付费最优）或
`ZHIJI_TAVILY_API_KEY`（Tavily，免费额度）；都不配则必应中国 + DuckDuckGo
双引擎兜底。`ZHIJI_DEEPSEEK_SEARCH=1/0` 可强制开/关原生搜索。

### 7.3 检索扩写——内置同义词，可加自己课程的叫法

检索共**四路**：原查询关键词、**同义/中英扩写**、两字词短词路、语义向量，
结果加权融合。所以：

- 资料里写「特征值」，你问「**本征值**」也能召回；资料写「队列」，你问
  「**queue**」也能召回——内置约 40 组等价术语（中文异名 + 中英对照），
  零配置即生效、不消耗 API；
- 想加自己课程里的叫法，写个 JSON 指过去即可（内置表仍生效）：

  ```bash
  # data/synonyms.json —— 每项 = 一组等价术语
  # [["微积分", "高等数学"], ["范式", "normal form"]]
  # .env 追加：
  # ZHIJI_SYNONYMS_FILE=data/synonyms.json
  ```

扩写词只是**补一路召回**并降权参与排序，不会挤掉原查询的字面命中。

## 八、数据存在哪里

| 路径 | 内容 |
| --- | --- |
| `data/zhiji.db` | **全部业务数据**：知识库（文档/片段/向量）、错题与练习题、掌握度与记忆、项目与会话消息、聊天附件记录、日程任务、LangGraph 检查点（会话历史） |
| `data/attachments/` | 聊天里的图片原文件（`/raw` 接口按归属校验后提供） |
| `data/backups/` | 手动备份目录 |

两个路径都可用环境变量覆盖：

```bash
ZHIJI_DATABASE_PATH=/tmp/study.db uv run zhiji "计算 1 + 1"
```

**备份（WAL 模式下也安全，推荐）**：

```bash
uv run python -c "import sqlite3,time;s=sqlite3.connect('data/zhiji.db');d=sqlite3.connect(f'data/backups/zhiji-{time.strftime(\"%Y%m%d-%H%M%S\")}.db');s.backup(d);d.close();s.close()"
```

**清空数据**：删掉主库文件即可（重启后自动重建空库）。`-wal` / `-shm` 是 SQLite 的
写前日志与共享内存文件，只删主库会让它们变成孤儿，一起删更干净：

```bash
rm -f data/zhiji.db data/zhiji.db-wal data/zhiji.db-shm
```

> ⚠️ 清空会同时删掉会话历史、知识库和日程——**先备份**。历史对话在
> LangGraph 检查点里还留着，必要时可用 `scripts/recover_sessions_from_checkpoints.py`
> 从备份库重建会话（见交接文档第五节）。

## 九、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 回答为空 / 只有一行空白 | 推理型模型把输出预算花在"思考"上 | 设 `ZHIJI_MAX_OUTPUT_TOKENS=4096`（或更大） |
| 命令一直停在"确认保存？" | 这是 HITL，在等你输入 | 输入 `y` 或 `n`；非交互场景加 `--yes` |
| 检索"没有找到相关片段" | 该知识库为空，或查询词完全不在资料里（检索有原词/同义扩写/短词/语义四路，但资料里确实没这个知识点时也是无解） | 先沉淀/上传一些资料；换个更贴近资料的说法；`docs/使用指南.md` 7.3 可加自定义同义词 |
| Word/PPT/Excel 资料搜不到内容 | 二进制资料是**原样秒传**的，还没建检索索引 | 打开该资料 → 点「**解析入库**」（PDF/Word/PPT/Excel 均支持；.doc/.ppt 老格式不支持解析，可下载原文） |
| 解析提示"没有可提取的文本" | 文件是扫描件/纯图 | 暂需手动整理后以笔记形式入库（视觉兜底在路线图上） |
| 前端报「无法连接后端」 | 后端 dev server 随会话回收了 | 重新执行 `./scripts/dev.sh`（或 `uv run uvicorn zhiji.interfaces.api:app --port 8011`） |
| 上传图片提示不支持 | Mock 模式不能识图 | 在 `.env` 里配真实模型（deepseek-flash 已实测支持图片转写） |
| 出题提示"没有可用于出题的新片段" | 该库的片段都出过题了（避免重复出题） | 换个知识库，或上传/编辑新资料 |
| 出题数量比选的少 | 实际生成数受"未用过的片段数"限制 | 正常行为，进度条里的 total 是真实候选数 |
| `ModuleNotFoundError: langchain_openai` | 没装可选依赖 | `uv sync --extra openai` |
| 想完全不联网跑 | 默认就是 Mock | 不要设 `ZHIJI_LLM_PROVIDER=openai` 即可 |
| `database is locked` | 同一数据库被多个进程同时写 | 串行运行命令；或换一个 `ZHIJI_DATABASE_PATH` |

## 十一、用接口走复习闭环 / 日程

界面之外，也可以直接调接口（完整清单见 [参考/API一览.md](参考/API一览.md)）：

```bash
# 上传一份资料（TXT / Markdown / PDF）或一张图片（走视觉转写，需真实模型）
curl -F "library=高等数学" -F "file=@导数笔记.md" \
  http://127.0.0.1:8011/api/knowledge/upload

# 记录一条误区
curl -X POST http://127.0.0.1:8011/api/feedback -H 'Content-Type: application/json' \
  -d '{"library":"线性代数","question":"什么是特征值？","note":"我把特征向量搞混了"}'

# 出题（Mock 下出模板题；接真实模型则由模型写题）
curl -X POST http://127.0.0.1:8011/api/practice/generate -H 'Content-Type: application/json' \
  -d '{"source":"mistakes","count":3}'

# 流式出题：每出一题推一帧进度（SSE）
```
