# 使用指南

> 从零把 StudyGraph 跑起来，十分钟走完"算题 → 沉淀笔记 → 检索资料"的闭环。
> 想理解内部原理，读 [架构设计](架构设计.md)。

## 一、前置条件

- **Python 3.12+**
- **[uv](https://docs.astral.sh/uv/)**（依赖与虚拟环境管理）
- 可选：一个 OpenAI 兼容平台的 API Key（用真实模型时才需要；默认 Mock 不需要）

## 二、安装

```bash
uv sync
```

这一步会创建 `.venv` 并安装 LangGraph 等依赖。默认**不装** `langchain-openai`——
只有接真实模型时才需要它。

## 三、第一次运行（Mock，零成本）

```bash
uv run studygraph "帮我算一下 7 * 9"
```

预期输出：

```text
（模拟模型）根据工具返回的结果：63
```

这句话背后发生的事：意图被识别为"计算" → 路由到计算子智能体 → 模型请求调用
计算器工具（参数 `7 * 9`）→ 工具返回 `63` → 模型据此给出回答。**全程不联网、
不花额度。**

## 四、走一遍学习闭环

```bash
# 1. 沉淀一条笔记（写操作会先请求确认）
uv run studygraph "记住：我在准备月底的微积分测验"

#    如果不想交互确认，用 --yes 自动同意
uv run studygraph "记住：我在准备月底的微积分测验" --yes

# 2. 检索刚沉淀的内容
uv run studygraph "我的笔记里怎么讲微积分测验的？"
```

第 1 条命令会先打印：

```text
[需要确认] 保存到「日常沉淀」：《记住：我在准备月底的微积分测验》
  预览：记住：我在准备月底的微积分测验
  确认保存？(y/N)
```

输入 `y` 才落库——这就是 Human-in-the-Loop。

### AI 私教怎么聊（教学人格）

StudyGraph 的回答遵循「私教」总纲（三条红线）：**个人数据优先**（你的笔记 /
错题本里有的先检索再答，并标注出处）、**引导优先于告知**（先给思路提示和分步
小问题，不直接甩答案）、**贴合掌握水平**（按你各学科的掌握度调整讲解深度）。

值得在聊天里试的话：

```bash
# 苏格拉底式讲解：不给完整答案，一步步引导你推导
uv run studygraph "讲一下定积分和不定积分的区别"

# 错题归因：检索你的误区记录，统计同类错误频次（需要先记过错题）
uv run studygraph "帮我分析一下我的错题，我哪里错了"

# 贴合掌握水平：薄弱学科多用类比讲基础，强势学科讲本质讲拓展
uv run studygraph "我的线性代数学得怎么样？接下来怎么复习？"
```

## 五、启动 Web 界面（推荐）

```bash
# 首次：安装前端依赖
cd frontend && npm install && cd ..

# 一键起后端（8011）+ 前端（3000）
./scripts/dev.sh
```

打开 <http://localhost:3000>。前端默认连 `http://127.0.0.1:8011`，可用环境变量覆盖：

```bash
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8011
```

### 界面导览

左侧全局侧栏：上方是功能导航（**AI 对话 · 错题练习 · 今日复习 · 日程 · 知识库**），
下方是**课程空间**（会话按课程分组、默认折叠、鼠标拖右缘可调宽 180–340px，双击恢复默认）。
底部是用户信息。

| 页面 | 能做什么 |
| --- | --- |
| **聊天** `/` | 流式打字回答；回答上方是**过程卡片**（理解问题 / 制定计划 / 工具调用，可折叠）；欢迎页有数据卡片与 GitHub 式**提问热力图**；＋菜单里可上传文件、选检索学科、开关「允许完全访问」 |
| **知识库** `/knowledge` | 目录树（搜索 / 折叠 / 右键新建删库删资料）+ 内容区 + AI 问答栏；支持上传 TXT/MD/PDF/**图片**（图片走视觉转写） |
| **笔记阅读** `/knowledge/doc/[id]` | 三栏：共享文件树 + 正文 + 右侧双 tab（AI 助手 / 目录大纲），面板可折叠、可拖拽调宽 |
| **错题练习** `/practice` | 两个 tab：**错题本**（记一条误区 + 按错误类型智能分类，每条可「出变式题」）· **专项练习**（默认基于错题：挑几条 → 选难度/数量 → 生成 → 右侧**牌堆复习**，自评后卡片飞出换下一题） |
| **今日复习** `/plan` | 到期题 / 薄弱学科 / 近期误区指标卡 + 学习活跃度热力图 + 今日任务清单 + 掌握度 + token 用量 |
| **日程** `/schedule` | 收件箱（未排期的想法）+ 固定 06:00–24:00 时间轴；一键把想法排进当天最早空档 |

在界面里试这几句，体验三种不同能力：

```text
帮我算一下 7 * 9               → 调计算器工具，回答里带 63
我的笔记里怎么讲微积分测验的？ → 检索你的资料并给出处
记住：我在准备月底的微积分测验 → 弹出确认框，确认后落库
```

### 聊天里可以做的三件"非打字"的事

1. **传附件**：点 ＋ → 上传文件，或直接把 PDF/图片**拖进**输入框，也可以 **Cmd+V 粘贴截图**。
   附件会随下一条消息发给模型；图片上传后可以点缩略图全屏预览。
   （图片识别需要真实模型；Mock 模式下上传图片会提示配置真实模型。）
2. **开关权限**：＋菜单里的「允许完全访问」——打开后，保存笔记这类敏感操作不再逐次弹确认框；
   开启时 ＋ 按钮右上角有个小红点提示。
3. **换空间**：输入栏下方一行可切换本次对话归属的项目空间（记忆也按空间隔离）。

### 日程怎么用（收件箱 → 时间轴）

想用日程时的一个典型流程：

```text
1. 想起来一件事 → 点「＋ 新收件箱任务」或右下角 FAB，只写标题（不选时间）→ 先放收件箱
2. 有空了 → 收件箱里点「安排到今天 ›」→ 自动落进当天最早的空档
3. 想指定时间 → 点收件箱卡片打开编辑，用自绘的时间选择器（时/分双列，5 分钟一档，
   也有「现在」「上午 09:00 / 晚上 19:00 / 睡前 22:00」快捷键）与日期选择器（迷你日历）
4. 时间轴上 → 点右侧圆圈打勾表示完成（卡片划掉、变浅）；点卡片任意位置即可编辑
5. 空档处 → 鼠标悬在空白时段会出现「＋ 在这里加一件事」，点一下即以该时刻新建
```

排期规则（确定性，不调用模型）：时间轴固定 06:00–24:00；「安排到某天」取当天
**最早放得下的空档**，今天则从当前时刻之后开始找。

## 六、命令行参数

| 参数 | 作用 |
| --- | --- |
| `message`（位置参数） | 本轮要说的话 |
| `--thread <id>` | 会话 id。相同 id 会**接着上一次**继续（断点持久化），默认 `local` |
| `--user <id>` | 用户标识（默认 `local`） |
| `--yes` | 自动同意所有需要确认的操作（HITL） |

继续一段旧对话：

```bash
uv run studygraph "接着上一题，再解释一下" --thread math
```

## 七、接入真实模型

任何 OpenAI 兼容平台都可以。推荐把配置写进项目根目录的 `.env`（Git 忽略，
程序启动时**自动加载**，无需手动 source）：

```bash
uv sync --extra openai

# .env 内容（DeepSeek-V4.1-Flash 示例，API 模型名 deepseek-flash）：
# STUDYGRAPH_LLM_PROVIDER=openai
# STUDYGRAPH_MODEL=deepseek-flash
# STUDYGRAPH_OPENAI_BASE_URL=https://api.deepseek.com/v1
# STUDYGRAPH_OPENAI_API_KEY=你的密钥
# STUDYGRAPH_MAX_OUTPUT_TOKENS=4096

uv run studygraph "讲解一下导数的几何意义"
```

也可以用环境变量临时覆盖（优先级高于 `.env`）。完整变量清单见
[`.env.example`](../.env.example)。注意：推理型模型务必设
`STUDYGRAPH_MAX_OUTPUT_TOKENS=4096`，避免输出被"思考"吃光导致空回答。

> 2026-07 起 DeepSeek 的 `deepseek-chat` / `deepseek-reasoner` 型号已退役，
> 统一使用 `deepseek-flash`（V4.1-Flash）或 `deepseek-v4-pro`。

## 八、数据存在哪里

| 路径 | 内容 |
| --- | --- |
| `data/studygraph.db` | **全部业务数据**：知识库（文档/片段/向量）、错题与练习题、掌握度与记忆、项目与会话消息、聊天附件记录、日程任务、LangGraph 检查点（会话历史） |
| `data/attachments/` | 聊天里的图片原文件（`/raw` 接口按归属校验后提供） |
| `data/backups/` | 手动备份目录 |

两个路径都可用环境变量覆盖：

```bash
STUDYGRAPH_DATABASE_PATH=/tmp/study.db uv run studygraph "计算 1 + 1"
```

**备份（WAL 模式下也安全，推荐）**：

```bash
uv run python -c "import sqlite3,time;s=sqlite3.connect('data/studygraph.db');d=sqlite3.connect(f'data/backups/studygraph-{time.strftime(\"%Y%m%d-%H%M%S\")}.db');s.backup(d);d.close();s.close()"
```

**清空数据**：删掉主库文件即可（重启后自动重建空库）。`-wal` / `-shm` 是 SQLite 的
写前日志与共享内存文件，只删主库会让它们变成孤儿，一起删更干净：

```bash
rm -f data/studygraph.db data/studygraph.db-wal data/studygraph.db-shm
```

> ⚠️ 清空会同时删掉会话历史、知识库和日程——**先备份**。历史对话在
> LangGraph 检查点里还留着，必要时可用 `scripts/recover_sessions_from_checkpoints.py`
> 从备份库重建会话（见交接文档第五节）。

## 九、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 回答为空 / 只有一行空白 | 推理型模型把输出预算花在"思考"上 | 设 `STUDYGRAPH_MAX_OUTPUT_TOKENS=4096`（或更大） |
| 命令一直停在"确认保存？" | 这是 HITL，在等你输入 | 输入 `y` 或 `n`；非交互场景加 `--yes` |
| 检索"没有找到相关片段" | 该知识库为空，或查询词完全不在资料里 | 先沉淀/上传一些资料；换个更贴近资料的说法 |
| 前端报「无法连接后端」 | 后端 dev server 随会话回收了 | 重新执行 `./scripts/dev.sh`（或 `uv run uvicorn studygraph.interfaces.api:app --port 8011`） |
| 上传图片提示不支持 | Mock 模式不能识图 | 在 `.env` 里配真实模型（deepseek-flash 已实测支持图片转写） |
| 出题提示"没有可用于出题的新片段" | 该库的片段都出过题了（避免重复出题） | 换个知识库，或上传/编辑新资料 |
| 出题数量比选的少 | 实际生成数受"未用过的片段数"限制 | 正常行为，进度条里的 total 是真实候选数 |
| `ModuleNotFoundError: langchain_openai` | 没装可选依赖 | `uv sync --extra openai` |
| 想完全不联网跑 | 默认就是 Mock | 不要设 `STUDYGRAPH_LLM_PROVIDER=openai` 即可 |
| `database is locked` | 同一数据库被多个进程同时写 | 串行运行命令；或换一个 `STUDYGRAPH_DATABASE_PATH` |

```bash
uv run pytest -q --basetemp=/tmp/sg-pytest   # 169 passed（本机沙箱须指定 basetemp）
uv run ruff check src tests scripts

# 前端门禁（沙箱内 npm run build 会被拦，用这两个替代）
```

```bash
# 评测门禁：有基线时掉超过容差 → 退出码 1
uv run studygraph-eval retrieval --dataset evals/datasets/retrieval.json \
  --baseline evals/baselines/retrieval.json
uv run studygraph-eval intent --dataset evals/datasets/intent.json \
  --baseline evals/baselines/intent.json

# 回合诊断：把一次会话读成诊断树
uv run studygraph-trace --thread <thread_id>
```

测试全部跑在确定性 Mock 上，**不消耗任何 API 额度**。

## 十一、用接口走复习闭环 / 日程

界面之外，也可以直接调接口（完整清单见 [参考/API一览.md](参考/API一览.md)）：

```bash
# 上传一份资料（TXT / Markdown / PDF）或一张图片（走视觉转写，需真实模型）
curl -F "library=高等数学" -F "file=@导数笔记.md" \
  http://127.0.0.1:8011/api/knowledge/upload

# 记录一条误区
curl -X POST http://127.0.0.1:8011/api/feedback -H 'Content-Type: application/json' \
  -d '{"library":"线性代数","question":"什么是特征值？","note":"我把特征向量搞混了"}'

# 出题（Mock 下出模板题；接真实模型则由模型写题）
curl -X POST http://127.0.0.1:8011/api/practice/generate -H 'Content-Type: application/json' \
  -d '{"source":"mistakes","count":3}'

# 流式出题：每出一题推一帧进度（SSE）
curl -N -X POST http://127.0.0.1:8011/api/practice/generate/stream \
  -H 'Content-Type: application/json' \
  -d '{"source":"knowledge_base","library":"数据结构","count":3,"difficulty":"auto"}'

# 到期题 / 作答自评（again | hard | good | easy）
curl http://127.0.0.1:8011/api/practice/due
curl -X POST http://127.0.0.1:8011/api/practice/answer -H 'Content-Type: application/json' \
  -d '{"question_id":1,"rating":"good"}'

# 今日复习建议 / 提问热力图
curl http://127.0.0.1:8011/api/study/plan
curl "http://127.0.0.1:8011/api/chat/activity?days=84"

# 日程：新建收件箱任务 → 一键安排到今天 → 看当天时间轴
curl -X POST http://127.0.0.1:8011/api/schedule/tasks -H 'Content-Type: application/json' \
  -d '{"title":"复习特征值","duration_minutes":45}'
curl -X POST http://127.0.0.1:8011/api/schedule/tasks/1/arrange
curl "http://127.0.0.1:8011/api/schedule?date=$(date +%F)"
```
