# 参赛材料 · StudyGraph 智能学习助手

> 面向**全国大学生数字媒体科技作品及创意竞赛**的申报材料。
> 申报赛道：**（十三）智慧教育与智能软件类**。
>
> **三个诚实说明**（写材料前先读）：
> 1. **材料必须与实际一致**——竞赛把"材料与当前完成状态一致"列为前置审查条件。
>    本目录每条技术主张都能在 [02-主张与证据核对表](02-主张与证据核对表.md) 找到代码证据；
>    每个数字都能在 [03-评测证据包](03-评测证据包.md) 找到出处。
> 2. **作品名与团队信息待团队确认**——见 [06-前置条件自查](06-前置条件自查.md)。
> 3. **界面状态**：后端与 Agent 能力已完整；前端目前为**单页聊天演示版**，
>    知识库 / 练习 / 今日复习等界面在建设中。涉及界面的材料小节已标注「待界面定稿」。

## 阅读顺序

```text
答辩准备：  01（讲清作品）→ 03（拿证据）→ 07（话术与追问预案）
录制演示：  08（分镜脚本，照做）

```

## 维护约定

- 材料中每个数字必须能在 [03-评测证据包](03-评测证据包.md) 找到出处。
- 材料中每条技术主张必须能在 [02-主张与证据核对表](02-主张与证据核对表.md) 找到代码证据。
- 代码一旦影响上述判定，必须同步更新 02 与 03。
