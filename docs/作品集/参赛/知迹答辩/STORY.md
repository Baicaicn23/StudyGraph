# STORY.md · 知迹 答辩 PPT 叙事

## ① 意图

- **目标受众**：「全国大学生数字媒体科技作品及创意竞赛」赛道十三（智慧教育与智能软件类）的**评审专家**，教育背景与技术背景混杂，单页停留 15–30 秒。
- **核心目标**：讲完后评委相信三件事 —— ① 它解决的是一个真实存在的学习痛点，不是演示用的壳；② 它是一套**可评测、可解释**的 Agent 工程系统，不是套壳聊天机器人；③ 它的边界是**自己说出来的**，不是被问出来的。
- **PPT 长度**：10 页（Hero 配额 3 页 = 30%，取上限）。
- **视觉调性**：学术严谨 / 证据驱动 / 蓝白克制 / 零装饰。
- **内容边界**：
  - **必讲**：痛点场景、五步学习闭环、洋葱分层 + LangGraph 状态图、三个技术承诺（最小权限 / 人在环 / 可评测）、评测与测试证据、诚实边界。
  - **不讲**：把「计划中」的功能当已完成（在线监控面板 / evaluator-optimizer / Reranker 一律不出现在成果口径里）；不写具体团队人名（未定）。
  - **禁碰**：虚构数据、编造引用、无代码证据的能力声称。

- **Hero 页定位**：01（封面，默认）、07（证据数字，中段高潮）、10（结束页，默认）→ 3/10 = 30%，且 07 与 10 之间隔了 08、09 两页 supporting，01 与 07 相隔五页。
- **rhythm 曲线**：peak(01) → valley(02) → peak(03) → valley(04,05) → peak(06) → peak(07) → valley(08) → peak(09) → peak(10)。最长连续 valley 为 2 页，未触发 ≥3 页的强制打断。
- **非对称版式预算**：8/10 页使用非对称版式（80% ≥ 40% 硬要求）。其中 `左大图+右侧文字`（04、09）与 `非对称双栏`（02、06）合计 4 页 = 40%，正好卡在上限。
- **对称版式预算**：仅 2 页（01 封面、10 结束页），用满配额。
- **相邻不重复校验**：01 全屏视觉 → 02 非对称双栏 → 03 上大图+下方卡片 → 04 左大图+右侧文字 → 05 左标题+右内容 → 06 非对称双栏 → 07 巨型数字+洞察 → 08 左标题+右内容 → 09 左大图+右侧文字 → 10 居中金句，全篇无相邻同版式。
- **`N卡片横排` 使用 0 次**（上限 2 次，本片以结构图与数据锚点替代）。
