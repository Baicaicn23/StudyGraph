# 怎么把提示词发给豆包

> 面向：拿到 `prompts/p01.md … p16.md` 的人。**不需要懂技术，照着做就行。**

---

## 一、最快的路径（推荐）

### 第 1 步 · 打开豆包的「图像创作」

| 用什么 | 怎么进 |
| --- | --- |
| **网页**（推荐，屏幕大看得清） | 打开 <https://www.doubao.com> → 左侧/顶部选 **图像创作**（或「AI 绘图」） |
| **App** | 打开豆包 App → 输入框上方的 **+ / 图片** 按钮 → 选 **图像创作** |

> 认得"图像创作"就行。找不到就直接问豆包："帮我生成一张图"，它会切过去。

### 第 2 步 · 复制提示词

打开 `prompts/p01.md`（在 VS Code / Xcode / 任何编辑器里），把**第一个代码块整段选中复制**：

````markdown
```text
画面上方有一行清晰端正的黑色中文标题文字：「整理资料，出题，复习——三件事，一个应用」…
```
````

> ⚠️ **只复制代码块里的内容**，不要把 `## 复制这段发给豆包` 这行标题和 ``` 围栏一起复制进去。
> 围栏粘到豆包会变成奇怪的一串符号。

**更省事的办法**：在 VS Code 里打开这个文件，鼠标移到代码块上会出现**复制按钮**，点一下就整段复制。

### 第 3 步 · 粘贴 + 生成

1. 粘贴到豆包的提示框
2. **选比例 16:9**（这一步别漏，漏了出的是方图，PPT 里要重新裁）
3. 点生成

### 第 4 步 · 挑图 + 下载

豆包一般一次给 4 张。**逐张看**：

- 标题文字对不对？（逐字看，尤其看有没有缺笔画、错字）
- 主体完整吗？（有没有被裁掉）
- 是不是浅色调、光从右上来？

选中最好的那张 → 下载 → **改名为 `p01.png`**（或按下面「文件命名」表的规则）→ 存进
`docs/作品集/参赛/知迹答辩/figures/`。

### 第 5 步 · 下一页

打开 `prompts/p02.md`，重复第 2–4 步。**做完 16 页再统一排版**。

## 二、关键操作技巧

### 技巧 1 · 一致性靠"以图生图"，不靠祈祷

16 页要看起来像一套，光靠文字描述不够稳。**从第 3 页起，用第 2 页满意的图当参考图**：

1. 在豆包界面点**「参考图」/「上传图片」**，上传 p02 满意的成品
2. 提示词照抄 p03 的
3. 加一句：`保持与参考图完全一致的光线方向、材质质感、色调与阴影角度`

这样豆包会锁住光照和材质，翻页时不串味。**这是整套图看起来专业与否的最大杠杆。**

### 技巧 2 · 不满意时用"改"而不是"重生成"

重生成是重新掷骰子，越改越跑偏。**豆包支持图像编辑**：

- 把不满意的图上传成参考图
- 追加一句具体的修改要求，比如：
  - `把漏斗改成哑光陶瓷质感，不要金属感`
  - `光线改成从右上方 45 度照入，阴影更柔和`
  - `整体再亮一点，背景更接近纯白`
  - `标题文字位置往上移，不要压住主体`

**一次只改一件事**。同时提五个要求，它会顾此失彼。

### 技巧 3 · 提示词追加语（应急用）

| 情况 | 在提示词末尾追加 |
| --- | --- |
| 图偏暗 / 偏冷 | `brighten the image, warm up the color temperature, keep shadows very soft` |
| 标题出现错字/缺笔画 | `the Chinese headline must be rendered with perfectly correct, complete characters` |
| 误生出了多余文字 | `remove everything except the specified headline, no other text or numbers` |
| 质感不够"3D" | `more pronounced three-dimensional form, real material texture, stronger sense of depth` |
| 构图太挤 | `more breathing room around the subject, wider composition` |
| 背景不干净 | `clean seamless background, remove all distracting elements` |

### 技巧 4 · 数字绝不交给模型

**图上不要出现任何数字**。检索权重 1.0 / 0.5 / 0.8、MRR 0.9714、35 题这些，
一律**留到 PPT 里用文本框叠**。模型写数字错一位就是编造数据，答辩现场被追问就麻烦了。

如果某张图实在想带数字（比如 p08 的四路权重），**先只出图，数字后加**。

### 技巧 5 · 每页出 3–4 张候选

别只生成一次就用。**同一个提示词多跑几次**，挑最好的那版。豆包每次结果都不一样，
这是正常现象。

## 三、验收清单（每张图都要过）

下载前逐条打勾：

- [ ] **标题文字与要求完全一致** —— 逐字核对，不要"看着像就行"
- [ ] 标题没有缺笔画、没有错字、没有变形字符
- [ ] **图上没有任何数字**（除标题里的汉字外）
- [ ] 主体完整，四边没被裁
- [ ] 整体是**浅色调**（白/米白/浅灰），不是深色
- [ ] 光从**右上方**来，阴影柔和
- [ ] 材质是**哑光**的（不要镜面、不要镀铬、不要霓虹）
- [ ] 没有人物（p07 最多一只手）
- [ ] 与前面几页的光线和色调**能接上**

任何一条不过 → 换候选，或用技巧 2 改。

## 五、常见问题

**Q：豆包说"内容可能涉及风险"？**
A：检查提示词里有没有"手臂""血""身体"这类词。p07 如果被拦，把描述改成
"一支笔悬停在半空被一块半透明挡板拦住"，不出现人。

**Q：出图比例不是 16:9？**
A：生成后在豆包里选「重新生成」并指定比例；或者出 4:3 再在 PPT 里裁。
**优先在生成时就选对**，后期裁会破坏构图。

**Q：连续几页风格差异很大？**
A：说明没用参考图。回退：挑一张最满意的当参考图，后续每页都上传它 + 追加
"保持与参考图完全一致的光线方向、材质质感、色调"。

**Q：标题文字位置老压住主体？**
A：在提示词末尾追加 `move the headline to the top edge with generous empty margin above
the main subject, do not overlap`。

**Q：文字写对了但字体不像设计稿？**
A：追加 `typeset like a professional design layout, clean modern Chinese sans-serif,
balanced letter spacing`。

**Q：能不能让豆包一次出多张不同角度？**
A：可以，一次会给你 4 张。但**不要一次做组图**——每页的提示词是独立的，
按页做更可控。

**Q：不用豆包，用别的模型行不行？**
A：行，提示词是通用的。但**带中文标题的页优先用豆包/Seedream**（中文渲染约 98%），
其他模型的中文准确率明显低一档（Nano Banana 约 65%）。实在不行就用英文版提示词 +
后期在 PPT 里叠中文。

## 六、做完之后

1. 16 张图放进 `figures/`
2. 新建 16:9 PPT，底色 `#F7F2E7`（浅米白）
3. 每页：放图 → **标题已经在图上了，不要再叠一遍** → 正文要点和所有数字用文本框叠
4. 页边距统一 1.2 cm，底部一条 `#C9BFA8` 细线 + 右下角页码
5. 最后读一遍：只看标题，能不能连成一条完整论证
