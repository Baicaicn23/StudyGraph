> **这份文档回答什么**：这份 PPT 长什么样——画布、配色、字体、版式、每页的视觉重心。
> 配套 `STORY.md`（叙事逻辑）与 `slides/*.slide`（逐页实现）。
>
> **风格分支**：**学术风**（`design-principle.academic.md`）——本项目是高校竞赛答辩，
> 场景明确属于学术/科研汇报，命中该分支。**不另生 DESIGN.md 的自由度**，

## 〇、三条不可让渡的原则

### 原则 1 · 撑满，不靠留白撑场面

学术风硬闸门第 1 条：内容页 C 区累计高 **≥476px**、宽 **1200px**。
**留白不是风格，是没写够。** 这一条直接回应"看起来太空"——太空=内容不足，不等于克制。

### 原则 2 · 证据优先于修辞

每一页的主视觉必须是**可验证的东西**：流程图、机制图、数据、真实界面截图、代码位置。
**不允许**用装饰插画充当论据。配图（生图）只用在封面、收束这类"不需要论证"的页面。

### 原则 3 · 严肃，不卖萌

- 禁：emoji、卡通、扁平吉祥物、圆球编号、渐变大字、感叹号营销句式
- 禁：把工程问题说成"痛点"、把技术说成"黑科技"、把边界说成"未来展望"
- 要：**用工程语言讲工程问题**（"失效场景""可验证的证据""明确的技术选型取舍"）

## 一、画布与母版

**画布**：1280 × 720（16:9）。安全边距：左右 **40**，上 **0**，下 **0**。

### 页眉模式：**A1**（深蓝实色顶条）——全篇锁定

| 区 | 范围 | 规则 |
| --- | --- | --- |
| A 页眉 | y 0–56 | 深蓝 `#1E4FA8` 实色顶条，高 56px。全篇一致 |
| B 标题块 | y 56–148 | 主标 34px Bold `#0E3F8C`；副标 20px `#4A5568` |
| C 内容区 | y 148–664 | **必须铺满 1200×476 起** |
| D 页脚 | y 664–720 | 左侧"知迹 · 赛道十三" 14px `#8B97A8`；右侧页码 15px `#1E4FA8` |

- 封面（p01）与收束（p16）可省略 A/D，用整版构图。
- **标题块右侧不放装饰小图**，全篇位置严格一致。

### 底部结论条（贯穿 p02–p15）

C 区底部固定一条 **56px 高**的结论条：`#E8EFF8` 底 + 顶部 2px `#1E4FA8` 细线，
内含 20px `#0E3F8C` 文本。**每页都要有**——它是"这页的结论"，
保证只读结论条就能读完整篇论证。

## 二、色板（≤4 种 hex，锁定全篇）

| 角色 | hex | 用途 | 配额 |
| --- | --- | --- | --- |
| **主蓝** | `#1E4FA8` | 顶条、编号、强调、细线 | 蓝族 35–55% |
| **藏蓝** | `#0E3F8C` | 主标题、深底块、重点文字 | — |
| **浅蓝** | `#E8EFF8` | 卡片底、结论条底、表头浅底 | 0–35% |
| **白 / 极浅灰** | `#FFFFFF` / `#F7F9FC` | 页面底、卡底 | 30–55% |
| 文本三阶 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅 | — |
| 线框 | `#D6DCE5` | 卡片描边、表格线 | — |
| 警示红 | `#D9534F` | **仅用于"未做/边界/风险"**，单页 ≤3% | 红黄合计 ≤5% |
| 数据黄 | `#FFC107` | **仅用于核心数字高亮**，单页 ≤3% | 同上 |

**禁**：紫、粉、玫红、橙、绿大色块、彩虹渐变、金色、纯黑大底、渐变作卡片背景。
**深蓝实色卡**：单页 ≤1 张，全篇 ≤3 张，**多卡页禁用**。

## 三、字体（≤2 套家族）

| 家族 | 用途 |
| --- | --- |
| **思源黑体 / PingFang SC** | 全篇正文、标题、表格、标签（90% 内容） |
| **Times New Roman** | 仅英文长标题（封面）、引文、代码标识符 |

**禁**：楷体、行书、毛笔、艺术字、空心字、3D 字、超过 2 套家族。

### 字号阶梯（硬下限，不得低于）

| 层级 | px | 用途 |
| --- | --- | --- |
| 封面中文主标 | 60 | p01 |
| 封面英文长 title | 34 Bold Serif | p01 |
| 章节大数字 | 96–120 Bold | p02 / p15 的编号 |
| B 区主标 | **34 Bold** | 每页标题（低于 32 返工） |
| 卡内标题 | **24–28 Bold/600** | 卡片小标（低于 24 返工） |
| 正文 | **22–26** | 段落（低于 22 返工） |
| 表格 | 18–20 | 表头表体 |
| KPI 巨数字 | **72–104 Bold** | 数据强调 |
| 注解 / 页脚 | 14–16 | 单位、来源、页码 |

**对比度**：≥4.5:1。深底放白字，浅底放 `#1A2230` 或 `#0E3F8C`。

### 每页自检（动笔前逐条确认）

- [ ] 母版三区齐全（A 顶条 / B 标题 / C 内容 / D 页脚）
- [ ] **总高 ≤720px**：`padding-top + 标题区 + 内容区 + gap + padding-bottom ≤ 720`
- [ ] C 区内容累计高 ≥476px、宽 =1200px
- [ ] **底部结论条存在**（p02–p15 每页都要）
- [ ] 本页主视觉占 C 区面积 ≥30%
- [ ] **≥1 个视觉锚点**（≥44px 元素，或 ≥40% C 区面积的图）
- [ ] 与上一页**最大元素面积比 > 1.5:1** 或版式结构明显不同
- [ ] 只用本文件列出的 hex（≤4 主色）与 2 套字体
- [ ] 正文 ≥22px、卡内标题 ≥24px
- [ ] 红色只出现在"未做/边界"，黄色只出现在核心数字
- [ ] **图上没有数字**（数字全部在 PPT 文本框里）
- [ ] 内容占比 30–85%

- **需要氛围**的（p01 封面、p07 闸门、p16 收束）→ **生图**；
- 其余页靠**版式 + 数据 + 表格**撑起来，不靠插图。

## 六、真实界面截图的使用

已有 `assets/ui-knowledge.png`（知识库页）、`assets/ui-practice.png`（练习页）。
**这两张是真实系统截图**，属于 L1 证据级视觉，优先于任何生图。

使用规范：
- 用 `<Image>` 组件 + 淡描边（1px `#D6DCE5`）+ 极浅阴影，像"贴在页面上的照片"
- **不要加圆角过大、不要加滤镜、不要改色**——它是证据，要保持原样
- p04 与 p14 各用一张，配图注说明"来自实际运行界面"
