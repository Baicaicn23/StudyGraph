## 〇、录制前准备（不录，约 10 分钟）

### 0.1 选运行模式 ★必备（第一个要做的决定）

| 模式 | 命令 | 画面观感 | 什么时候用 |
| --- | --- | --- | --- |
| **真实模型（推荐录制用）** | `ZHIJI_LLM_PROVIDER=openai ./scripts/dev.sh` | 回答是真人水平、过程流里是**真实的工具调用链**、流式打字自然 | **正式录制**——评委要看真东西 |
| Mock（兜底） | `./scripts/dev.sh` | 回答是固定文本，过程流也能走，但内容明显像"回放" | 网络/额度出问题时的备份；录「工程侧」镜头（评测、测试）也用得上 |

> ⚠️ **必须带 `ZHIJI_LLM_PROVIDER=openai` 这个前缀**，光跑 `./scripts/dev.sh` 会进 Mock。
> 原因：`dev.sh` 里写了 `export ZHIJI_LLM_PROVIDER="${ZHIJI_LLM_PROVIDER:-mock}"`，
> 而 `config.py` 用的是 `load_dotenv(override=False)`——**已存在的环境变量不会被 `.env` 覆盖**，
> 所以 `.env` 里即使写着 `openai` 也会被脚本设的 `mock` 顶掉。这是个"静默降级"，
> 界面看不出区别，但回答会变得像固定文本。**开录前务必先看下面的健康检查。**

**用真实模型**：确认仓库根目录 `.env` 里有 `ZHIJI_LLM_PROVIDER=openai`、`ZHIJI_MODEL=deepseek-flash`，以及 Embedding 三项配置（`ZHIJI_EMBEDDING_BASE_URL` / `ZHIJI_EMBEDDING_API_KEY` / 模型名）。然后：

```bash
cd /Users/momo/Dev/Projects/Competitons/数字媒体科技作品及创意竞赛/我的项目/TeachX_langGraph
ZHIJI_LLM_PROVIDER=openai ./scripts/dev.sh   # 后端 8011 + 前端 3000（显式指定真实模型）
```

- 后端健康检查：`curl -s http://127.0.0.1:8011/api/health` → 期望 `{"status":"ok","provider":"openai"}`。
  **如果这里显示 `"mock"`，先别开录**——视频里回答会很假。启动脚本现在也会把生效的模型模式打出来，看那行也行。
- 前端：<http://localhost:3000>
- ⚠️ **必须用 `localhost` 打开前端，不要用 `127.0.0.1`**——Next 16 会把后者当跨源，页面不 hydrate，所有按钮点了没反应（页面 HTML 全 200，极易误判成软件坏了）。
- 若接入真实模型后出现空回答，确认 `ZHIJI_MAX_OUTPUT_TOKENS=4096`。
- ⚠️ **只起后端也可以**：前端已经在跑时（`next dev` 还活着），只要后端在 8011 上，刷新页面就能看到数据；反过来**后端没起时页面是空的**（这不是 bug，是前端拿不到数据）。

## 二、对话核心：过程流 + 检索 + 教学人格（1:00–3:30）★必备

> 这一幕是全片的**技术核心**（过程流面板是最大的差异化点），不要快进。

**镜头 2.1（40 秒）提问并展示过程流**

- 操作：在输入框输入附 A 的 **提问 ①**，回车。
- 预期：
  1. 回答**逐字流出**；
  2. 助手卡片标题是「**知迹 智能体**」，旁边显示「**已处理 42s**」这类耗时，**过程流面板在回答过程中自动展开**；
  3. 面板里能看到**单行活动**（转圈 + 工具名 +「参数」），顶部有**链路摘要**，例如「已完成 3 步 · knowledge_search ×1」；
  4. 回答结束后过程面板**自动收起**；点旁边的箭头（提示「**展开过程**」）可重新展开；**点开某一步能看到「输入：…」「结果：…」**。
- 讲解词："注意左边这个**过程流面板**——它把这一回合做过的事按步骤摊开：**先理解问题，再判断要不要查资料，查了几次，查到了什么**。这不是事后编的日志，是 LangGraph 状态图里真实走过的节点和工具调用。我们把「执行细节」放在这个面板里，正文里**只留结论**——所以你既看得见它怎么想的，又不会被工具名和报错干扰。"（展开一步，指着「输入 / 结果」）"每一步的入参和返回都能查。"

**镜头 2.2（35 秒）带出处的检索**

- 操作：输入附 A 的 **提问 ②**（问一个知识库里确实有的定义）。
- 预期：回答**基于你自己的资料**，并标出**出处（哪个知识库、哪份资料）**；如果命中的是多页 PDF，出处里会带「**第 N 页**」。
- 讲解词："它说的是**我自己的笔记里的内容**，并且标了出处——多页讲义还能落到**第几页**。检索走的是 **FTS5 中文全文 + 向量 + 同义词扩写 + 两字词兜底**四路召回，再用 **RRF 加权融合**——所以换个说法也能命中，比如「本征值」能搜到写着「特征值」的资料。"
- 可选加映（15 秒）：再问一句 `牛顿第二定律里的合外力是什么意思？`，引用会落到《牛顿运动定律 · 习题课讲义》的**具体页码**，很适合展示"PDF 按页引用"这个点。

**镜头 2.3（25 秒）教学人格：结构化的回答**

- 操作：指着刚才那条回答的结构。
- 预期：回答**结论先行并加粗**、正文用**分层列表或表格**、结尾**落到下一步动作**（不是开放式结尾）。
- 讲解词："我们的私教人格不是随便答。总纲里写了**输出规格**：结论先行、分层表达、结尾必须落到下一步该做什么。而且它会**按你的掌握度调整讲法**——同一道题，对薄弱学科讲得更细。"

**镜头 2.4（20 秒）检索模式：智能选库 / 指定库**

- 操作：点输入框上方的检索模式按钮（默认显示「**智能检索**」）→ 弹层里切到「**指定知识库**」→ 勾选两个库 → 关闭；顶部副标题应出现「· 检索限定：…」。
- 预期：弹层两个 tab「**✦ 智能检索**」「**指定知识库**」，manual 下有「检索范围（可多选）」和「**清空选择（检索全部学科库）**」。
- 讲解词："检索范围可以**交给模型判断**该查哪些库，也可以**手动锁死**只查某几个库——精读某一门课时很有用。"

## 三、人在环 + 附件 + 图片（3:30–6:00）★必备

**镜头 3.1（45 秒）HITL：写操作必须先确认** ★必备

- 操作：输入附 A 的 **提问 ③**（要求把要点存进知识库）。
- 预期（两步都要拍到）：
  1. 聊天里出现**中断条**：「**已暂停等你确认：把「…」存进高等数学-微积分**」，右侧标签「**待确认**」；
  2. 同时弹出遮罩确认框：标题「**需要你的确认**」，说明「助手想把一条笔记保存到你的知识库：」，卡片显示「**「库名」· 标题**」+ 预览，底部两个按钮「**取消**」「**确认保存**」；

- 讲解词："**AI 不会擅自改我的数据**。所有写操作都会停下来等我确认。这一点是**执行层强制**的，不是写在提示词里"劝"它——提示词只是劝告，拦得住才算承诺。"

**镜头 3.2（30 秒）收束条：一条回答延伸出四个动作** ★必备

- 操作：等回答结束，鼠标扫过回答下方的四个按钮。

**镜头 3.3（35 秒）附件三路 + 图片视觉转写** ★必备

- 操作：**用拖拽**把一张图片拖进输入框 → 上传完成后点缩略图**预览大图** → 附一句话发出（附 A **提问 ④**）。

- 预期：拖入时输入框高亮；附件 chip 带缩略图（提示「点击预览大图」）；回答里显示它**读懂了图里的内容**。
- 讲解词："三种方式都能传：**用「+」菜单选文件、直接 Cmd+V 粘贴、或者拖进来**。图片会先由**视觉模型转写成 Markdown** 再入库——所以**拍照的课件和板书也能被检索到**，不只是电子文档。"
- （口播补充）"知识库的上传用的是同一套转换。"

**镜头 3.4（20 秒）「+」菜单全景（可选）**

- 操作：点输入框左侧「**+**」，缓慢扫过菜单。
- 预期：`上传文件（PDF/图片/文本）`、`上传资料到知识库`、`引用最新错题`、`选择检索学科`、分隔线、`允许完全访问` 开关。
- 讲解词："「引用最新错题」把错题本内容直接带进这一轮对话；「允许完全访问」是给熟练用户的免确认开关——默认关着。"

**镜头 3.5（20 秒）会话自动保存 + 历史回放（可选）**

- 预期：会话**已自动保存并自动起了标题**；点回去历史在，**过程流也能重放**。
- 讲解词："会话自动保存、自动起标题。历史点回来，连当时的执行过程都能重看。"

## 五、学习闭环：错题 → 变式题 → 复习（8:30–11:00）★必备

> 这是产品的**第二条主线**（知识库是第一条），也是"期末有题可复习"的落点。

**镜头 5.1（40 秒）错题本 + 智能分类** ★必备

- 操作：点侧栏「**错题练习**」（默认在「**错题本**」tab）→ 鼠标扫过一条误区卡 → 点「智能分类」区一个类型标签筛选 → 清掉筛选。
- 预期：副标题「先把错因写清楚，再针对它出变式题——练到会为止。」；每条卡有**学科标签 + 错误类型标签**（概念混淆 / 步骤遗漏 / 条件误读 / 计算失误 / 表述不清）+ 相对时间 + 「**核心误区**」红块；「智能分类」区提示「按错误类型聚合，点标签筛选」。
- 讲解词："错题本记的不是"哪道题错了"，而是**错在哪一步、哪个概念混了**。所以每条都带**错误类型**，可以按类型聚合回炉——「我这一周概念混淆特别多」这种判断，是它替我做的。"

**镜头 5.2（50 秒）从错题出变式题（流式生成）** ★必备

- 操作：在某条误区卡底部点「**出 3 道变式题 ›**」→ 自动跳到「**专项练习**」tab 并带上这条错题 → 点「**生成变式题**」。
- 预期：切过去后可见来源「**基于错题**」、标题「选择要强化的错题」、难度四档（自动/基础/进阶/迁移）、数量步进器；点生成后按钮文案变成「**正在出第 1/3 题…**」，下方有**骨架动画卡**和真实进度条。
- 讲解词："它从这条错因**出一道新题**——不是原题重做，是**变式**。难度按我的掌握度自动分档。生成过程是流式的，进度是真实的。（指进度条）"

**镜头 5.3（45 秒）牌堆复习 + 看详解 + 自评 + 掌握度** ★必备

- 操作：在「**今日待复习**」卡片里写下思路（可只写一句）→ 点「**看详解**」→ 等 3-5 秒出现**参考答案与关键步骤** → 再点「**掌握了**」→ 观察卡片飞出、出现「**已记录自评：掌握度 X% · N 天后再来**」→ 再点一张的「**星标本题**」。
- 预期：卡片有「第 N 题 · 共 M 题」、来源标签「**来自你的误区**」、区块「你当时记下的误区」；作答框下方是「**看详解**」入口，展开后是「**参考答案**」（浅青底）与「**关键步骤**」（编号列表）；自评四档 = 「**又忘了 / 有点难 / 掌握了 / 太简单**」；点击后显示掌握度百分比与下次复习天数。
- 讲解词："答完**自评**四个档，系统就更新**掌握度**并安排**下次复习时间**——这就是间隔重复。不过我更想让你注意的是这个**看详解**：写完再看参考答案，**先自己对一遍**，再判断"掌握了"还是"又忘了"，这样自评才不是凭感觉。（详解展开）详解是**按需生成**的——只有你点开才让模型写，写完入库，同一道题不会再算第二次；不看的题就不花钱。这是我们对成本的默认态度。"
- 提示：**详解要真实模型**（Mock 模式会提示"需要接入真实模型"）。首次约 3-5 秒，建议**先预演一次**让它进缓存，正式录时秒开。
- 提示：看完详解**仍然要自评**——自评才是驱动间隔重复的那一步，别跳过。
- 提示：「**学科掌握度**」环在左栏，自评后回来指一下，数字会动。

**镜头 5.4（25 秒）记一条新误区（可选）**

- 操作：回「错题本」tab → 右侧「**记一条误区**」填「你卡在哪」+ 选错误类型 → 点「**记录**」。
- 讲解词："刚才那条错因就是在这里记的——**当时的问题**和**你卡在哪**分开填，所以出题能精准针对错因。"
