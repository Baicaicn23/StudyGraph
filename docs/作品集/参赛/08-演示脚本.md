# 08 · 演示脚本（手动演示 / 录屏）

> 按顺序照做，每段给了 **操作 → 预期 → 讲解词**。看到"预期"里的东西再往下走。

## 〇、环境准备（录之前）

```bash
uv sync
uv run studygraph-demo --reset      # 播种：5 学科 / 15 笔记 / 3 误区
uv run pytest -q                    # 预期 104 passed（可选，证明测试全绿）
./scripts/dev.sh                    # 后端 8011 + 前端 3000
```

- 后端：<http://127.0.0.1:8011>（健康检查 `/api/health` 返回 `{"status":"ok","provider":"mock"}`）。
- 前端：<http://localhost:3000>。
- 默认 **Mock 模型**：**零成本、无网络依赖**，演示不会因额度/网络出错。

> 若已接入真实模型，务必确认 `STUDYGRAPH_MAX_OUTPUT_TOKENS=4096`，避免出现空回答。

## 一、开场：这是什么（约 20 秒）

| | |
| --- | --- |
| 操作 | 停在首页 |
| 预期 | 看到 StudyGraph 名称与聊天框 |
| 讲解词 | "这是 StudyGraph，一个面向大学生的 AI 学习助手。它解决一个很具体的问题：**作业散在各个课程系统里，期末就没有题可复习**。所以它的核心是——把学科知识库做成平时的沉淀罐，期末从库里长出复习材料。" |

## 二、学科知识库 + 检索（约 40 秒）

| | |
| --- | --- |
| 操作 | 打开知识库列表；问"我的笔记里怎么讲定积分和不定积分的区别？" |
| 预期 | 回答基于**你自己的资料**，并标出处（哪个库、哪份资料） |
| 讲解词 | "我已经沉淀了五个学科的资料。检索走的是 **FTS5 中文分词 + 向量 + RRF 融合**，所以换个说法也能命中，而且每个回答都有出处。" |

> 命令行等价演示：
> ```bash
> uv run studygraph "我的笔记里怎么讲定积分和不定积分的区别？"
> ```

## 三、人在环：沉淀（约 30 秒）

| | |
| --- | --- |
| 操作 | 说"记住：我在准备月底的微积分测验" |
| 预期 | **弹出确认框**（显示库名、标题、预览），确认后才落库 |
| 讲解词 | "写操作会先请求确认——**AI 不会擅自改动我的数据**。这是被执行层强制的承诺，不是提示词里的劝告。" |

## 四、学习闭环：错题 → 出题（约 40 秒）

| | |
| --- | --- |
| 操作 | 展示一条已记录的误区（如"把特征向量和基向量搞混"）→ 从错题出题 |
| 预期 | 生出一道**针对该知识点的新题**，题面标注"来自你的误区" |
| 讲解词 | "学生记下的误区会自己长出练习题。模型写题，写不出来就退回模板——**出题永远不会因为模型问题而失败**；而且一条误区只出一道题。" |

## 五、间隔重复 + 掌握度（约 30 秒）

| | |
| --- | --- |
| 操作 | 作答并用"Good"自评 |
| 预期 | 掌握度上升、显示下次复习时间（如 3 天后） |
| 讲解词 | "自评会更新掌握度，并安排下次复习——这就是**间隔重复**。" |

## 六、今日复习（约 20 秒）

| | |
| --- | --- |
| 操作 | 打开"今日复习" |
| 预期 | 汇总到期题 / 薄弱学科 / 近期误区，给出"今天先做什么" |
| 讲解词 | "它不只回答，还会告诉你**今天该复习什么**。" |
