# 05 · 第三方来源与授权清单

> 竞赛要求"第三方数据、模型、代码、字体、图片等资源来源及授权情况清楚"。
> 本清单逐项列出**来源、许可证、处理方式**。

## 一、本项目原创部分

| 资源 | 说明 | 授权 |
| --- | --- | --- |
| 后端与 Agent 运行时 | 作者原创（领域/应用/基础设施/接口四层） | 本项目采用 Apache-2.0（见 `LICENSE`） |
| 前端界面代码 | 基于 Next.js 官方脚手架（create-next-app）搭建，界面组件由作者编写 | MIT（脚手架）+ 作者原创 |
| 演示语料 | 5 学科 15 份复习笔记，**作者自行编写**（定义/例子/易错点，非教材扫描件） | 作者原创，无第三方版权 |
| 评测数据集 | 检索 6 题 + 意图 15 句，作者自行标注 | 作者原创 |
| 作品标识 | 名称、图标由作者自制 | 作者自制 |

## 二、开源依赖（均为宽松许可证）

| 依赖 | 用途 | 许可证 |
| --- | --- | --- |
| LangGraph / LangChain Core | Agent 状态图编排、消息与模型接口 | MIT |
| FastAPI / Starlette / Pydantic | HTTP 接口与数据校验 | MIT |
| Uvicorn | ASGI 服务器 | BSD-3-Clause |
| aiosqlite / SQLite | 异步检查点与本地存储 | MIT / Public Domain |
| python-multipart | 文件上传 | Apache-2.0 |
| pypdf | PDF 文本抽取 | BSD-3-Clause |
| Next.js / React | 前端框架 | MIT |
| Tailwind CSS | 样式 | MIT |
| react-markdown / remark-* / rehype-* | Markdown / 数学公式 / 代码高亮渲染 | MIT |
| KaTeX / highlight.js | 公式与代码渲染 | MIT / BSD-3-Clause |

> 均通过包管理器引入，随包保留各自许可证；本项目不修改其源码。

## 三、模型与服务条款

| 服务 | 用途 | 说明 |
| --- | --- | --- |
| 任意 OpenAI 兼容平台（如 DeepSeek） | **可选**的真实对话/出题模型 | 由用户自行申请与付费，遵守其服务条款 |
| 任意 OpenAI 兼容 Embeddings | **可选**的真实向量模型 | 同上 |
| 默认 Mock 模型 | 演示与测试 | 作者自研，不访问任何第三方服务 |

## 四、第三方品牌与商标

**本项目前端不使用任何第三方品牌 logo 或商标**用于标识功能——界面仅使用自制的
作品标识。MCP 配置示例中若提到官方 Filesystem server，仅作为**互操作说明**，
不涉及商标使用。
