## 三、模型与外部服务

| 服务 | 用途 | 授权与合规说明 |
| --- | --- | --- |
| 自研确定性 Mock 模型（**默认**） | 演示与全部自动化测试 | 作者自研，**不访问任何第三方服务**，零成本零额度 |
| 任意 OpenAI 兼容平台（如 DeepSeek） | **可选**的真实对话 / 出题模型 | 由使用者自行申请与付费，须遵守其服务条款；密钥不随作品提交 |
| 任意 OpenAI 兼容 Embeddings 服务 | **可选**的真实向量模型 | 同上 |
| DuckDuckGo / Tavily / 必应中国 / 博查 | **可选**的联网搜索后端 | 各自服务条款；需使用者自行配置凭据；默认不启用 |
| edge-tts（Microsoft Edge 朗读服务） | **作品评审视频的中文配音** | 通过开源 `edge-tts` 客户端调用微软公开朗读端点，属该服务的使用条款范围；用于本作品的自制科普视频，非再分发内容 |
| MCP 社区 server（如 Filesystem server） | **可选**的外部工具接入示例 | 仅作互操作说明，不随作品分发其代码 |

> **默认离线**：本作品默认配置下**不调用任何第三方服务**。上述外部服务均为可选，评审期间保持默认 Mock 模式即可完整体验全部功能。
