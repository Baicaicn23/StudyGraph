# 知迹 · 使用演示视频脚本

> 目标时长 **3 分 30 秒**（规范建议 ≤5 分钟）。每段给「做什么 / 说什么 / 看点」。
> **画面比例 16:9，浏览器窗口 1440×900 全屏**，录屏工具不限（QuickTime / OBS / macOS 截图工具均可）。
> **录制前必做**：先 `uv run zhiji-demo --reset` 播种 → 重启后端 → 打开首页确认有内容。

---

## 录制前检查（3 分钟）

```bash
cd 项目根目录
uv run zhiji-demo --reset        # 播种：6 个库 / 24 份资料 / 7 条错因 / 3 条日程
```

**已为你预置好的状态**（当前库里就有，不用重跑播种）：
- 6 个学科库 · 24 份资料 · 52 个检索块
- 7 条错因（concept 3 / condition 2 / step 1 / wording 1）
- **数据结构 3 道变式题 + 计算机网络 1 道**已生成，**其中数据结构第 2 题（考 BST 查找复杂度）的详解已缓存**——录制时点「看详解」是秒出，不用等
- 今日复习页有 6 道到期题
- 后端 8011（真实模型模式）+ 前端 3000 都在跑

浏览器打开 <http://localhost:3000>，**刷新一次**，确认练习页能看到题目。

### 录制设置

| 项 | 值 |
| --- | --- |
| 分辨率 | 1920×1080（16:9）。只能 1280×720 也可，规范是"建议" |
| 浏览器窗口 | 1440×900，按 `Cmd+Ctrl+F` 全屏 |
| 录制工具 | QuickTime / OBS / macOS 截图工具都行 |

### ⚠️ 录制前必须清掉这两样

**1. 左下角「1-Insight ×」浮标**
不在代码里，是浏览器扩展注入的。**出现在画面里会被当成作品的一部分**。
- Chrome：`chrome://extensions` → 找到对应的 Insight 类扩展 → 关闭
- 或直接用**无痕窗口**（`Cmd+Shift+N`）录制

**2. 右上角「真实模型」徽章**
界面右上角有个红色小标显示当前模型模式。这是开发调试用的，录进成片会显得像未完成品。
- 若介意：录之前切到 Mock 模式重启后端即可（`./scripts/dev.sh` 默认就是 Mock）
- 若不介意：留着无妨，它反而说明了"可接真实模型"

**3. 顺带检查**
- 地址栏别露出来（`Cmd+Ctrl+F` 全屏已隐藏）
- 别用带书签栏的窗口

## 段落 1 · 开场：它是什么（0:00–0:25）

**画面**：停在首页欢迎态，展示三张数据卡片和提问热力图。

**说什么**：

> 这是知迹，一个面向大学生的个人学习助手。它做三件事：**整理学习资料、自动出题、结合知识库复习**。
> 资料传进来，它按学科归好；然后按你的资料出题——不是网上找的题库；做错的方向，它会多出几道变式题。

**操作**：鼠标缓慢扫过侧栏的学科库列表，再移到三个功能入口（知识库 / 练习 / 今日复习）各停 1 秒。

> 🎯 这一段不要提技术名词。评委先要听懂"这东西解决什么问题"。

---

## 段落 2 · 资料从哪来（0:25–0:50）

**画面**：进入 **知识库** 页。

**说什么**：

> 先看资料库。左边按学科分好，右边是这份资料的原文和解析状态——每个文件都标了字数和有没有建好索引。

**操作**：
1. 点左侧「高等数学-微积分」→ 右侧展开该库的文件列表
2. 鼠标停在某个 PDF 上，指一下「已解析 / N 字」
3. 打开那份《极限与连续·复习讲义》，展示正文可读、页码可见

**说什么**（补一句价值）：

> 讲义进来是**原样秒传**——先落盘不解析，用到才建索引。所以传 100 页 PDF 不用等。

> 🎯 不用真去传文件。已有 24 份演示资料，够展示"资料被整理好"这个事实。传文件太慢，剪掉。

## 段落 3 · 问答带出处（0:50–1:35）★核心段

**画面**：回到 **AI 对话** 页，在课程空间选「高等数学」。

**说什么**：

> 现在问它一个真问题——注意看它不是直接答。

**操作**：
1. 在输入框输入：**`我的笔记里怎么讲定积分和不定积分的区别？`**
2. 回车，**让过程流完整跑完**（大约 15–25 秒，别急着切屏）

**关键：让评委看清过程流的三段**
- 「理解问题」→ 判定为检索类
- 「制定学习计划」
- 「检索知识库 · 命中 11 篇」+「查阅错题记录」

**回答出来后，说**：

> 看到没有，它先查了你的资料和错题，**再**回答。而且——

**操作**：鼠标点到回答里带 📍 出处的那一行。

**说什么**：

> 每个结论都能点回原文第几页。它不是"知道"，是**从你的资料里找到的**。

**再说一句（点题）**：

> 它没有一次性给你答案，而是先反问一句"你笔记里已经沉淀过这块了"，确认你是**没记住**还是**记混了**。

> 🎯 **本段是全片最重要的 45 秒**。真实模型每次输出略有不同，但三件事一定出现：① 过程流分步 ② 引用出处 ③ 苏格拉底式反问。
> ⚠️ 如果这次回答没引用出处，**重录这一段**——换问法：「我笔记里关于特征值是怎么讲的？」

## 段落 4 · 错了就记，记了就练（1:35–2:20）

**画面**：进入 **错题练习** 页（`/practice`）。当前已有 6 道待复习题。

**说什么**：

> 做错了怎么办？它不只记"错了"，**记错因**。

**操作**：
1. 左侧「错题本 / 专项练习」区，指出错题带着错因标签——**概念混淆、条件误读、步骤遗漏**这些
2. 右侧今日待复习（6），指着题目说它从哪来

**说什么**：

> 这道题是从你那条错因生成的——同一个考点，换个条件再出一道，叫**变式题**。

**操作**：
3. 在题目下方输入框**写两行思路**（提前想好，见下方示例）
4. 点「**看详解**」——**已缓存，秒出**

**说什么**：

> 详情节奏是懒生成的：第一次算，之后直接读缓存。

5. 点「**掌握了**」——展示掌握度当场变化

**说什么**：

> 自评完掌握度当场变，下次出题就按新的掌握度来。这就是闭环。

> 🎯 **思路可以直接念这段**（提前写在便签上）：
> 「BST 靠左小右大的性质，每次比较排除一整棵子树，所以查找取决于树高不是结点数。平均 O(log n)，退化成链就是 O(n)。」
>
> 这样念显得真懂，比"随便写点"可信得多。
>
> ⚠️ **难度值是英文**（basic/apply/transfer），但界面上是中文「基础/进阶/迁移」——
> 录制时点中文按钮即可，只是脚本里调用接口时要注意。
> ⚠️ 若想现场点「生成变式题」演"AI 出题"这个动作，**要接受 10–20 秒等待**；
> 想节奏紧凑就用预置的题（当前状态已备好）。

## 段落 5 · 今天该练什么（2:20–2:45）

**画面**：进入 **今日复习** 页（`/plan`）。当前显示 6 道到期题 + 7 条近期误区。

**说什么**：

> 打开这一页，它直接告诉你今天该练什么——到期题、薄弱学科、近期误区。

**操作**：
1. 扫过「今日待复习」的 6 道题
2. 手指过一下学科掌握度和活跃度热力图

**说什么**：

> 排期按间隔重复算法算：答错的马上再来，掌握了就拉长——1 天、3 天、7 天。

> 🎯 这段**不用多说，扫一眼即可**。别在这里展开讲算法，那是技术段的事。
> ⚠️ 时间紧就**砍掉整段**（见段落 6 的说明）——评审更在意"可验证"，不太在意功能多。

## 段落 6 · 收尾：凭什么信它（2:45–3:20）

**画面**：切到一张**代码或工程证据画面**——建议用终端跑评测。

**说什么**：

> 最后说凭什么信它。这些数字不是我们自己说的，是跑出来的。

**操作**：终端跑（提前开好窗口，或用录屏工具切成终端）

```bash
uv run zhiji-eval retrieval --dataset evals/datasets/retrieval.json \
  --baseline evals/baselines/retrieval.json
```

**说什么**（对着输出念）：

> 检索 35 题，Hit@3 和 MRR 都是 0.9714。关掉词面精排，掉到 0.9571——说明这一步是真的有用，不是摆设。
> 意图识别 15 句，准确率 1.0。全项目 **284 项自动化测试**，全程离线、不花一分钱额度。

**再说一句**：

> 还有一个我比较在意的点：**它不会偷偷改你的东西**。任何写操作都要你点确认——这是代码里强制的，不是提示词里求它的。

> 🎯 **如果时间紧，砍掉段落 5（今日复习），保留段落 6**——评审更在意"可验证"，不太在意功能多。

**画面**：回到首页。

## 剪辑提示

| 要点 | 做法 |
| --- | --- |
| **删掉所有等待** | 检索、出题、详解生成都要等——**录两遍**，第二遍只留等待后的结果，中间剪掉 |
| 过程流别剪 | 段落 3 的「理解问题 → 制定计划 → 检索 → 完成」是**最有说服力的画面**，留着 |
| 鼠标动作放慢 | 停留 1 秒再点，让评委看清点了哪里 |
| 加字幕**只加口播字幕** | 不要满屏文字；页面自带的内容不用再念一遍 |
| 背景音**不要** | 安静录，只留人声 |

## 风险预案

| 现场出问题 | 怎么办 |
| --- | --- |
| 真实模型回答慢/失败 | 切到段落 4、5、6，这些不依赖模型 |
| 回答里没有引用出处 | 重录段落 3，换问法 |
| 详解生成卡住 | 跳过"看详解"，直接自评 |
| 页面显示 "1-Insight" 角标 | 浏览器扩展注入的，用无痕窗口或禁用扩展重开 |
| 后端 8011 被占 | `lsof -nP -iTCP:8011 -sTCP:LISTEN` 找到 PID，`kill` 后重启 |
| 想要绝对稳定的画面 | 提前把 6 个页面的状态都走一遍，确认每个都有内容 |
