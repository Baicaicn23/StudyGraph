## 3、作品简介（必填 · 全文 533 字）

「知迹」是一个面向大学生的 AI 学习助手（Web 应用）。它针对一个具体痛点：**作业与讲义散落在各个课程平台与聊天工具里，平时没有整理的动力，等到期末想复习时，题和资料都已经找不回来。** 因此它的核心不是"更会聊天"，而是把**学科知识库做成平时的沉淀罐**——期末从库里长出复习材料。

它做这些事：按学科沉淀资料（PDF / Word / PPT / Excel 秒传并按页解析、拍照的板书由多模态模型转写成文字、也可直接手写笔记），基于自己的资料问答并**标注出处**；把错因记成带「错误类型」的错题，据此生成**变式题**，作答后可查看参考答案与关键步骤，并按自评更新掌握度、安排下次复习；再用「今日复习」汇总到期题、薄弱学科与近期误区，用「日程」安排什么时候做。

技术上，后端用 **LangGraph** 把一次学习回合做成**显式状态图**（意图路由 → 规划 → 模型与工具循环），并配齐 Agent 工程模块：工具最小权限（接口层与执行层双重校验）、**人在环**（写操作必须用户确认）、输入输出护栏、工具超时与重试、上下文压缩、模型路由与 token 成本控制、MCP 外部工具接入，以及检索与意图的**固定评测门禁**与回合诊断。全项目 **279 项自动化测试**（全程离线、零 API 消耗），检索基线 Hit@3 = 1.0、意图准确率 = 1.0。

## 4、创意来源（必填 · 全文 411 字）

创意来自团队自己在期末复习中的共同经历：课程作业、讲义和答疑记录分散在多个教学平台与聊天工具里，平时没有整理的动力，等想复习时，"题"和"资料"都已经找不回来了。我们意识到缺的并不是一个更聪明的问答机器人，而是**一个把日常碎片自动攒成复习材料的沉淀系统**——于是把"知识库"从"搜索用的资料夹"重新定位成"期末复习的原料库"。

第二个来源是对"AI 黑盒"的不信任：大模型给出答案时，用户无法判断它查了什么、有没有依据、会不会擅自改动自己的数据。因此我们把一次学习回合做成**显式的状态图**——意图判断、检索、工具调用、人工确认都是可见、可复现、可中断的步骤，**写操作必须经用户确认才落库**；再结合苏格拉底式引导与掌握度自适应，让它更接近"私教"而不是"答案机"。

在定位上，作品对应赛道「智慧教育与智能软件类」：既要解决真实学习场景里的问题，也要把 Agent 工程能力做成**可评测、可解释**的软件，而不是一个演示用的壳。

## 5、运行环境（必填 · 按本机实测填写）

**说明**：本项目是**单机本地运行**的 Web 应用，一条命令同时启动前后端，全部数据存于单个 SQLite 文件，**不需要单独安装数据库服务**。以下为本机（演示与开发环境）实测配置。

- **操作系统**：macOS 27.0.1（MacBook Pro，Apple M2 Pro 芯片，10 核 CPU）
- **内存 / 磁盘**：16 GB 内存；可用磁盘 342 GB
- **后端运行时**：Python 3.12.10（依赖与虚拟环境由 uv 0.12.19 管理）
- **前端运行时**：Node.js v22.22.2
- **数据库**：SQLite（Python 内置，随项目自动创建，无需独立服务）
- **浏览器**：Google Chrome 155（演示窗口 1440×900）
- **核心框架**：LangGraph 1.2.14、FastAPI 0.142.4、Next.js 16.4.0、React 19.3.0、Tailwind CSS 4
- **大模型**：可接入任意 OpenAI 兼容接口（演示使用 DeepSeek-V4.1-Flash）；向量检索可接入任意 OpenAI 兼容 Embeddings（演示使用智谱 embedding-3）；**未配置模型时可切换内置 Mock 模型完全离线运行**（自动化测试即走此模式，零 API 消耗）
- **常用软件**：macOS 预览（看图）、QuickTime Player（录屏）、iMovie（剪辑，系统自带）
- **网络**：检索与大模型调用需联网；离线时可运行全部内置演示数据与工程验证（测试与评测均离线）
