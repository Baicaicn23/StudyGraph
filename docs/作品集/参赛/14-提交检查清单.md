> **用途**：对照报名系统的上传栏目逐项打勾，避免漏交或格式不符。
> **打包目录**：`参赛打包/知迹_待填编号/`（编号待报名系统生成后回填）。

## 二、单独上传栏目的具体操作

### 2.1 参赛承诺书（截图里那一栏）

- 报名系统生成 → 核对**作品名称、成员信息、指导教师信息**与报名信息一致 → 打印 → **加盖公章**（学校教务处 / 二级学院 / 学校学科竞赛管理部门，三者之一即可）→ 扫描或拍照 → 上传（1 张图片或 1 个 PDF）。
- ⚠️ 承诺书内容若与报名信息不一致，属前置审查硬伤。**先核对再盖章**。

### 2.2 作品截图（≤10 张）

选 `01_作品及成果文件/作品截图/` 下 10 张，按文件名顺序上传：

| # | 文件 | 展示内容 |
| --- | --- | --- |
| 1 | `01-AI对话首页.png` | 欢迎页：数据卡片 + 提问热力图 |
| 2 | `02-AI对话-苏格拉底式讲解.png` | **真实模型输出**：讲义引用出处 + 拆成递进小问题引导 + 主动指出知识盲区 |
| 3 | `03-知识库页.png` | 知识库：学科树 + 资料列表 + 右侧问答区 |
| 4 | `04-资料原文阅读.png` | 三栏阅读页：目录树 + PDF 分页预览 + 文本视图 |
| 5 | `05-错题练习.png` | 错题练习：错因选择与变式题 |
| 6 | `06-错题本.png` | 错题本：按错误类型归档筛选 |
| 7 | `07-日程.png` | 日程：收件箱 + 时间轴排期 |
| 8 | `08-知识库问答-引用讲义.png` | **真实模型输出**：库内问答并标注讲义出处 |

> ✅ 全部为**作品实机运行截图**（非设计稿、非概念图），且第 2、8 张含真实模型的实际输出——直接证明"作品真的在跑"。
> ⚠️ 规范明确「不得用未实现的概念图替代真实成果」，本组 10 张全部为真实界面。

### 2.3 作品评审视频

- 文件：`知迹_作品评审视频.mp4`（125 MB，5′00″，3024×1964 / 120fps）。
- 规范建议：≤5 分钟 ✅ / MP4 ✅ / 分辨率 3024×1964（超 1080P 建议）✅ / 16:9 ✅ / 单文件 125 MB ≤1GB ✅。
- 内容为**真实界面录屏**（非配音讲解片）：对话问答带出处、错因分类与变式题、资料库阅读、今日复习全流程。
- ✅ 3024×1964 远超规范的 1920×1080 建议；MP4 / 16:9 / 时长 5 分钟均在规范内。

### 2.4 作品汇报 PPT

- 文件：`知迹_汇报.pptx`（13 MB，18 页）。
- 规范参考上限：1 个文件、200 MB ✅。
- ⚠️ **该 PPT 为纯图片型**（每页一张 PNG，无文字层）。优点：排版绝对可控；缺点：评审无法检索/复制文字，也不便后续修改字号。若需改内容，需重出图。

## 三、压缩包结构（规范第十节参考结构）

```

│   ├─作品截图/                     （8 张）
│   └─知迹_作品汇报.pptx
├─02_作品展示视频/                   ← 按需 ✅
│   └─知迹_作品评审视频.mp4
├─03_作品介绍文档.pdf                ← 建议 ✅
├─04_运行或使用说明.pdf              ← 按需 ✅
├─05_补充成果材料/                   ← 按需 ✅
│   ├─评测证据包.pdf
│   └─主张与证据核对表.pdf

```

**命名符合规范建议**：「作品名称_材料名称」。压缩包与目录内**不含**参赛单位、团队成员、指导教师身份信息。
