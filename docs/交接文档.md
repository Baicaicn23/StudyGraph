## 一、这个项目是什么（自包含简介）

**StudyGraph 是一个面向大学生的 AI 学习助手**，Web 优先（Next.js 16 前端 + FastAPI 后端 +
SQLite）。核心痛点：**作业散落在各课程系统里，平时不整理，期末没有题可复习**——所以
知识库是"平时的沉淀罐"，期末从库里长出复习材料（检索 → 出题 → 间隔重复 → 掌握度）。

技术上用 **LangGraph** 把一次学习回合做成显式状态图（`route → plan → agent ⇄ tools`），
配齐 Agent 工程模块：意图路由、工具最小权限、人在环（HITL）、护栏、工具可靠性、上下文压缩、
规划、模型路由、成本控制、MCP、评测门禁、回合 trace。

**项目定位**：**全国大学生数字媒体科技作品及创意竞赛（赛道十三：智慧教育与智能软件类）**
参赛作品。一切决策以"可交付、可演示、材料与代码一致"为准。

## 六、已知坑（完整清单，按优先级）

### 布局/CSS 坑（本轮踩过，别再踩）

- **flex 链上的 `truncate` 不生效 = 某层缺 `min-w-0`**。侧栏曾因 AppShell 的 aside
  只有 `w-56` 没有 `min-w-0`，被超长标题撑到入侵主区域。整条 flex 父子链都要能收缩。
- 自定义 CSS 效果（mask 渐变淡出）在用户浏览器不可靠——**UI 细节优先用最朴素的
  Tailwind 工具类**（`truncate` 省略号是最终定案，用户拍板）。
- eslint `react-hooks/set-state-in-effect`：effect 体内同步 setState 会报错。
  对策：数据加载改 `.then()` 链；派生状态用 `override ?? busy` 而不是 effect 同步；
  定时器里才 setState。
- MessageRow 这类带提前 return 的组件，**hooks 必须放在 return 之前**。
- 跨页动作传递如果依赖"导航后重新挂载"，目标页已是当前页时会失效——要补 window
  事件兜底（参考 `sg-chat-action` + `sg:chat-action` 双通道模式）。

## 八、设计决策记录（防翻案，含理由）

| 决策 | 理由 |
| --- | --- |
| 对话不允许跨项目移动 | 记忆按 project_id 隔离，移动会话=上下文与项目错配的脏数据 |

| 无 project_id 的请求兜底默认空间 | 否则记忆落 `project_id=''` 黑洞桶，表现为"记住又忘了" |
