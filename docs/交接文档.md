## 一、这个项目是什么（自包含简介）

**StudyGraph 是一个面向大学生的 AI 学习助手**，Web 优先（Next.js 16 前端 + FastAPI 后端 +
SQLite）。核心痛点：**作业散落在各课程系统里，平时不整理，期末没有题可复习**——所以
知识库是"平时的沉淀罐"，期末从库里长出复习材料（检索 → 出题 → 间隔重复 → 掌握度）。

技术上用 **LangGraph** 把一次学习回合做成显式状态图（`route → plan → agent ⇄ tools`），
配齐 Agent 工程模块：意图路由、工具最小权限、人在环（HITL）、护栏、工具可靠性、上下文压缩、
规划、模型路由、成本控制、MCP、评测门禁、回合 trace。

**项目定位**：**全国大学生数字媒体科技作品及创意竞赛（赛道十三：智慧教育与智能软件类）**
参赛作品。一切决策以"可交付、可演示、材料与代码一致"为准。

## 五、已知缺陷与坑（完整清单，按优先级）

### P1 缺陷（✅ 已于 2026-10-09 教学改造轮修复，含回归测试）

1. **~~知识库检索的库过滤失效~~（已修）**：LangGraph 各节点 contextvar 不跨节点
   传播，曾导致前端选了库仍检索全库。修复：`tools_node` 开头重新
   `set_current_libraries(state.get("knowledge_bases"))`（`user_id` 同样处理）；
   回归测试 `test_library_filter_survives_across_nodes` 用"两库同时命中同关键词"
   的布局锁死该行为。
2. **~~MCP 工具权限泄漏~~（已修）**：`AgentProfile` 增加 `mcp_enabled`（默认
   `False`），`allowed_tools` 只对显式授权的 tutor/retriever 并入 MCP 工具，
   `is_tool_allowed` 执行层用 `is_mcp_tool()` 再拦一次。测试
   `test_mcp_tools_only_for_authorized_profiles` 覆盖 schema 与执行两层。

### 环境坑（本机 WorkBuddy 沙箱特有）

- `npm run build` 会被 safe-delete 保护拦下（`SAFE_DELETE_BULK_CONFIRM_REQUIRED`）——
  **用 `npx tsc --noEmit` + dev server 路由 200 替代 build 验证**。
- pytest 默认临时目录会被沙箱拦（EEXIST）——**必须加 `--basetemp=/tmp/sg-pytest`**。
- 无头 Chrome 截图、osascript 窗口控制、ego-browser 在沙箱内均不可用——**视觉验证靠
  用户人工截图**，代码级审查 + impeccable detect 替代。
- 后端 dev server 与前端 dev server 会随会话结束被回收，重启：
  `uv run uvicorn studygraph.interfaces.api:app --port 8011` 与 `cd frontend && npm run dev`。

### Next.js 16 前端坑

- **新增动态路由（URL 带 `[参数]`）必须加 Suspense 边界**：`use(params)` 的组件和含
  `usePathname()` 的 AppShell 都要被 Suspense 包住，否则报
  "Blocking Route: usePathname outside of Suspense"（AppShell 已拆内外层处理，新路由照抄
  `/knowledge/doc/[id]/page.tsx` 的 DocPage/DocContent 拆分模式）。
- `cacheComponents` 下渲染期禁止 `Math.random()`（学科配色用名字哈希）。
- React 19 ESLint：effect 内同步 setState 要豁免注释或收进 useCallback；JSX 文本不用直引号。
- Python 字符串内层引号用「」。

### 后端坑

- 从节点里同步写 SQLite 会锁库（`database is locked`）——写库走 `asyncio.to_thread`，
  连接 WAL + busy_timeout（已修，别回退）。
- HITL 的 `GraphInterrupt` 必须原样上抛，不能被 try/except 吞掉。
- 图必须编译时带 checkpointer，否则 `interrupt()` 无效。
- 推理型模型务必设 `STUDYGRAPH_MAX_OUTPUT_TOKENS=4096`。
- FastAPI 查询参数用 `Query()` 不是 `Field()`。
- 自动测试必须走 Mock（零 API 消耗）；不碰 `data/` 与任何 Secret。

## 八、开发规则（必须遵守）

```text

→ 更新文档(README/架构/使用指南/参赛材料) → ruff + pytest + 前端 lint/tsc → commit
```

- 提交规范：`feat:` 功能与测试；`docs:` 文档与材料。推送：`git push`（凭据已配置）。
- `.workbuddy/`（Agent 本地记忆）已加入 .gitignore，**不要提交**。
- **绝不**：无验证声称完成、绕过评测门禁、把计划写成已完成、泄露 Secret。
